

# 🎮 **Rush Wings**

### *A fast-paced endless flying adventure powered by reflexes, timing, and precision*


![Rush Wings Poster](https://github.com/Fairooz2150/Rush-Wings/Assets/Sprites/Rush%20wings%20Poster.png)

Rush Wings is an addictive 2D arcade flying game where quick reactions and smart aiming are the key to survival. Fly endlessly through dangerous obstacle paths while facing a unique challenge — the pipes ahead begin fully attached, blocking your path completely.

To survive, you must aim carefully and shoot the target boards to separate the pipes and create a gap before crashing. Every second matters. Every shot counts.

🕊️ **Fly Fast. Aim Smart. Survive Longer.**

---

## ✨ **Features**

* 🎯 **Unique Shooting Mechanic** — shoot target boards to open paths
* 🕊️ **Endless Flying Gameplay** — survive as long as possible
* ⚡ **Fast-Paced Arcade Action** — simple controls with addictive gameplay
* 🧠 **Reflex & Timing Based** — quick thinking is essential
* 🌌 **Smooth 2D Visuals** — colorful and engaging game world
* 🏆 **High Score Challenge** — beat your best score
